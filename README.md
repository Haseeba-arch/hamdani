## 🚀 How to Run & Preview

### 1. Standalone Live Preview
Simply open `index.html` in any web browser to experience the complete responsive design with all interactive functionality.

### 2. Upload to Shopify
1. Compress this folder into a `.zip` archive.
2. In your Shopify Admin, navigate to **Online Store > Themes**.
3. Click **Add Theme > Upload zip file**.
4. Click **Publish** or **Customize** in the Shopify Theme Editor.
